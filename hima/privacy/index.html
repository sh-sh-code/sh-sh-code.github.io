HIMA プライバシーポリシー

制定日：2026年9月11日

Nagi Lab（以下「当方」）は、Android アプリ「HIMA」（以下「本アプリ」）における利用者の情報を、以下のとおり取り扱います。

1. 取得する情報

種類内容取得の方法
アカウント情報Google アカウントのメールアドレス、当方が発行する利用者 IDGoogle でのログイン時
プロフィールニックネーム、生年月日、性別、都道府県、プロフィール写真利用者の入力
利用状況「暇」状態のオン・オフと有効期限、最終利用日時本アプリの操作
やり取り送受信した「👋」、マッチの成立、メッセージの本文と送信日時本アプリの操作
安全のための記録ブロック・通報の内容と日時、利用停止の履歴本アプリの操作・当方の対応
端末と通知プッシュ通知の宛先トークン、端末の種類、OS のバージョン自動的に取得
利用分析・障害画面の表示や操作の記録、アプリの異常終了の記録自動的に取得
広告広告 ID、IP アドレス、端末情報、広告の表示・視聴結果広告の表示時に自動的に取得

2. 他の利用者に表示される情報

ニックネーム、年齢（生年月日から計算した数字のみ）、性別、都道府県、プロフィール写真、「暇」状態は、本アプリにログインしている他の利用者に表示されます。生年月日そのもの、メールアドレスは他の利用者に表示しません。メッセージは、やり取りの相手にだけ表示されます。

3. 利用目的

  1. 本アプリの提供（ログイン、プロフィールの表示、👋・マッチ・メッセージ機能、通知）
  2. 18 歳未満の方が利用できないようにするための年齢の確認
  3. ブロック・通報への対応、禁止行為の調査、利用停止など、利用者の安全を守るため
  4. 不具合の調査と修正、機能の改善のための分析
  5. 広告の表示と、広告を最後まで視聴したことの確認（視聴後に写真の閲覧などが解放される機能）
  6. お問い合わせへの対応

4. 外部サービスへの提供

本アプリは次の外部サービスを利用しており、各サービスの提供者に情報が送信されます。各社での取り扱いは、それぞれのプライバシーポリシーに従います。

サービス提供者用途
Firebase（Authentication、Cloud Firestore、Cloud Storage、Cloud Messaging、Remote Config、Analytics、Crashlytics）Google LLCログイン、データの保存、通知、設定の配信、利用分析、障害の記録
AppLovin MAX（および MAX 経由で広告を配信する広告事業者）AppLovin Corporation広告の配信と視聴の確認

これらのサービスの一部は日本国外にサーバーがあり、情報は国外で保存・処理されることがあります。上記のほか、法令に基づく場合を除き、本人の同意なく第三者に個人情報を提供しません。

5. 広告 ID について

広告の配信に広告 ID を使います。端末の設定（Google の設定 → 広告）から、広告 ID の削除やパーソナライズ広告の停止ができます。

6. 保存期間と削除

  • 情報は、アカウントを削除するまで保存します。
  • アカウントは本アプリ内の「マイページ → アカウント削除」から削除できます。アプリを使えない場合は、アカウントとデータの削除のページからご依頼いただけます。
  • 削除すると、プロフィール、写真、「暇」状態、👋 の記録は削除されます。送信済みのメッセージは、相手の画面から削除されない場合があります。
  • 禁止行為への対応や法令上の必要がある場合、ブロック・通報・利用停止の記録を、その目的に必要な期間保存することがあります。

7. 年齢について

本アプリは 18 歳以上の方のみを対象としています。18 歳未満の方の情報であることが分かった場合、そのアカウントを削除します。

8. 安全管理

通信は暗号化し、データへのアクセスは、本人と、本人が許可した範囲に限る設定にしています。非公開の情報（生年月日など）は、他の利用者に公開される情報とは別の場所に保存しています。

9. 開示・訂正・削除などのご請求

ご自身の情報の開示、訂正、利用の停止、削除をご希望の場合は、サポートに記載の窓口までご連絡ください。ご本人であることを確認したうえで、遅滞なく対応します。当方の氏名（名称）・住所についても、お問い合わせいただければ遅滞なくお答えします。

10. 改定

本ポリシーを変更する場合は、このページで告知します。重要な変更は本アプリ内でもお知らせします。
